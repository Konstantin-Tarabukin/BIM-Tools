# ADR

## ADR-001
(отказ от БД в пользу хранения в самом файле и обращаться к нему при открытии//синхронизации)
позволит избежать развертывания сервера с БД (SQL и проч.) 

## ADR-002
разделить сущности:

Изменение (Change) — само сообщение: автор, комментарий, список элементов, дата, приоритет.
Адресат (Recipient) — одна запись на каждую целевую модель (например, ОВ, ВК, КР).
Статус доставки (DeliveryStatus) — состояние для каждого адресата: отправлено, доставлено, прочитано, выполнено, отменено.

Так мы избежим ситуации, когда одно изменение имеет только один общий статус, хотя разные разделы находятся на разных этапах работы.


## ADR-003

Решение

Использовать события Revit для проверки новых уведомлений.

События

DocumentOpened
DocumentSynchronizedWithCentral
DocumentReloadedLatest

Причина

Пользователь гарантированно увидит новые изменения при открытии проекта, синхронизации или обновлении модели.

Статус

✔ Проверено экспериментально.
