# RevitCopyParams — Roadmap

## Sprint 1 — Основа журнала изменений ✅

Цель: создать минимально рабочий журнал изменений.

Реализовано:

* создание `ChangeRecord`;
* окно журнала изменений;
* окно создания записи;
* сохранение журнала в Extensible Storage;
* загрузка журнала;
* сохранение автора;
* сохранение даты;
* сохранение модели-источника;
* выбор моделей-получателей.

Статус: завершён.

---

## Sprint 2 — Уведомления между моделями ✅

Цель: передавать записи журнала пользователям связанных моделей.

Реализовано:

* чтение журналов загруженных связанных моделей;
* фильтрация записей по `TargetModels`;
* окно уведомлений;
* проверка уведомлений при открытии документа;
* проверка уведомлений после синхронизации;
* проверка уведомлений после Reload Latest.

Статус: завершён.

---

## Sprint 3 — Состояние прочтения ✅

Цель: сохранять персональное состояние прочтения уведомлений.

Реализовано:

* `NotificationStateService`;
* отдельное хранилище Extensible Storage;
* хранение прочитанных `Guid`;
* методы `IsRead` и `MarkAsRead`;
* массовая отметка уведомлений как прочитанных;
* статусы `Mine`, `New`, `Read`;
* WPF-конвертеры текста и цвета статуса;
* корректное определение статуса записи;
* сортировка журнала по статусу и дате.

Статус: завершён.

---

## Sprint 4 — UX журнала 🟡

Цель: сделать журнал удобным для повседневной работы.

Реализовано:

* открытие карточки двойным кликом;
* открытие карточки клавишей Enter;
* форматирование даты;
* сортировка по статусу и дате.

Осталось:

* [ ] счётчик непрочитанных записей;
* [ ] пустое состояние журнала: «Изменений нет»;
* [ ] фильтр «Все»;
* [ ] фильтр «Новые»;
* [ ] фильтр «Прочитанные»;
* [ ] фильтр «Мои».

---

## Sprint 5 — Привязка изменений к элементам 🔵

Цель: позволить автору прикреплять к записи изменённые элементы модели, а получателю — находить и показывать их в Revit.

### Этап 5.1 — Модель данных

* [ ] создать модель `ChangeElementReference`;
* [ ] хранить стабильный идентификатор элемента;
* [ ] хранить модель, в которой находится элемент;
* [ ] хранить категорию и отображаемое имя элемента;
* [ ] добавить список элементов в `ChangeRecord`;
* [ ] обеспечить совместимость со старыми записями без элементов.

### Этап 5.2 — Выбор элементов автором

* [ ] добавить кнопку «Выбрать элементы» в окно создания записи;
* [ ] временно скрывать окно создания записи на время выбора;
* [ ] разрешить выбор нескольких элементов активной модели;
* [ ] обработать отмену выбора клавишей Esc;
* [ ] вернуть окно после завершения выбора;
* [ ] показать количество выбранных элементов;
* [ ] добавить просмотр списка выбранных элементов;
* [ ] добавить удаление элемента из списка до сохранения записи.

### Этап 5.3 — Сохранение ссылок

* [ ] сохранять ссылки на элементы вместе с записью журнала;
* [ ] использовать `Element.UniqueId` как основной идентификатор;
* [ ] не использовать обычный `ElementId` как единственный постоянный идентификатор;
* [ ] сохранять резервные сведения:

  * категория;
  * тип;
  * имя;
  * исходный `ElementId`;
  * модель-источник;
* [ ] протестировать сохранение после синхронизации;
* [ ] протестировать повторное открытие документа;
* [ ] протестировать старые записи журнала.

### Этап 5.4 — Поиск элементов в исходной модели

* [ ] определить связанную модель по `SourceModel`;
* [ ] получить `RevitLinkInstance`;
* [ ] получить связанный `Document` через `GetLinkDocument()`;
* [ ] найти элемент в связанном документе по `UniqueId`;
* [ ] обработать незагруженную связь;
* [ ] обработать удалённый элемент;
* [ ] обработать изменение имени модели;
* [ ] обработать несколько экземпляров одной связи.

### Этап 5.5 — Список элементов в карточке

* [ ] добавить список прикреплённых элементов в `ChangeDetailsWindow`;
* [ ] отображать категорию, имя и идентификатор;
* [ ] показывать состояние:

  * найден;
  * удалён;
  * связь не загружена;
  * модель не найдена;
* [ ] добавить кнопку «Показать» для выбранного элемента;
* [ ] добавить кнопки «Предыдущий» и «Следующий».

### Этап 5.6 — Показ элемента

* [ ] получить ссылку на элемент связанной модели;
* [ ] выделить элемент через API выбора Revit;
* [ ] приблизить активный вид к расположению элемента;
* [ ] учитывать трансформацию `RevitLinkInstance`;
* [ ] протестировать планы;
* [ ] протестировать разрезы;
* [ ] протестировать 3D-вид;
* [ ] корректно сообщать, если элемент не виден на активном виде.

### Этап 5.7 — Последовательный просмотр

* [ ] хранить текущую позицию в списке элементов;
* [ ] показывать элементы по одному;
* [ ] переходить к следующему элементу;
* [ ] переходить к предыдущему элементу;
* [ ] отображать номер: «Элемент 2 из 7»;
* [ ] пропускать недоступные элементы с понятным сообщением.


### Этап 5.8 — Поиск подходящего вида

- [ ] проверить видимость элемента на текущем виде;
- [ ] определить уровень элемента;
- [ ] собрать планы, разрезы, фасады и 3D-виды;
- [ ] определить приоритет видов;
- [ ] проверить видимость экземпляра связи;
- [ ] преобразовать BoundingBox элемента в координаты основной модели;
- [ ] проверить пересечение с областью вида;
- [ ] активировать первый подходящий вид;
- [ ] добавить резервный переход на 3D-вид;
- [ ] протестировать элементы разных категорий.

### Этап 5.9 — Selection Box

- [ ] проверить SetReferences для элемента связи в Revit 2023;
- [ ] проверить сохранение выделения после переключения вида;
- [ ] протестировать ручную команду Selection Box;
- [ ] протестировать PostableCommand.SelectionBox;
- [ ] добавить кнопку «Показать в 3D»;
- [ ] обработать случай, когда команда недоступна.

### Этап 5.10 — Немодальный навигатор

- [ ] вынести действия Revit API в ExternalEvent;
- [ ] открыть окно элементов через Show();
- [ ] добавить «Предыдущий» и «Следующий»;
- [ ] сохранять выделение при работе с Revit;
- [ ] разрешить использование ленты и навигации Revit;
- [ ] корректно закрывать ExternalEvent и окно;
- [ ] исключить повторное создание навигатора.

Статус: запланирован. Высокий приоритет.
