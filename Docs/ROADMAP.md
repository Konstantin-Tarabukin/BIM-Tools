## Этап 8.7 — GitHub Releases ✅

Правила выбора:

* `draft = true` → игнорировать;
* `prerelease = true` → игнорировать;
* участвуют только стабильные Releases;
* выбирается максимальная подходящая версия;
* фактическая версия ZIP дополнительно проверяется через
  `UpdateInfo.json`.

Production-соглашение:

* stable Release имеет `draft = false`;
* stable Release имеет `prerelease = false`;
* тег имеет формат `vX.Y.Z`;
* имя ZIP соответствует версии;
* `UpdateInfo.json` содержит соответствующую версию.

Проверено:

* stable Release выбирается;
* draft Release игнорируется;
* prerelease Release игнорируется;
* суффикс тега сам по себе не определяет стабильность;
* выбирается максимальная стабильная версия;
* ZIP не используется как единственный источник версии;
* `UpdateInfo.json` дополнительно проверяет фактический пакет.

Статус: завершён.
