# RevitCopyParams — Roadmap

## Sprint 1 — Основа журнала изменений ✅

Цель: создать минимально рабочий журнал изменений.

Реализовано:

* создание `ChangeRecord`;
* окно журнала изменений;
* окно создания записи;
* сохранение журнала в Extensible Storage;
* загрузка журнала;
* сохранение автора;
* сохранение даты;
* сохранение модели-источника;
* выбор моделей-получателей.

Статус: завершён.

---

## Sprint 2 — Уведомления между моделями ✅

Цель: передавать записи журнала пользователям связанных моделей.

Реализовано:

* чтение журналов загруженных связанных моделей;
* фильтрация записей по `TargetModels`;
* окно уведомлений;
* проверка уведомлений при открытии документа;
* проверка уведомлений после синхронизации;
* проверка уведомлений после Reload Latest.

Статус: завершён.

---

## Sprint 3 — Состояние прочтения ✅

Цель: сохранять персональное состояние прочтения уведомлений.

Реализовано:

* `NotificationStateService`;
* отдельное хранилище Extensible Storage;
* хранение прочитанных `Guid`;
* методы `IsRead` и `MarkAsRead`;
* массовая отметка уведомлений как прочитанных;
* статусы `Mine`, `New`, `Read`;
* WPF-конвертеры текста и цвета статуса;
* корректное определение статуса записи;
* сортировка журнала по статусу и дате.

Статус: завершён.

## Sprint 4 — UX журнала 🟡

Цель: сделать журнал удобным для повседневной работы.

Реализовано:

* открытие карточки двойным кликом;
* открытие карточки клавишей Enter;
* форматирование даты;
* сортировка по статусу и дате.

Осталось:

* [ ] счётчик непрочитанных записей;
* [ ] пустое состояние журнала: «Изменений нет»;
* [ ] фильтр «Все»;
* [ ] фильтр «Новые»;
* [ ] фильтр «Прочитанные»;
* [ ] фильтр «Мои».

Дополнительно:

* [ ] при открытии журнала очищать `ReadIds` от `Guid`,
      которых больше нет ни в одной записи.
